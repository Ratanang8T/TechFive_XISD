ROLE-BASED DONOR MANAGEMENT WEBSITE
Matches the Android app role logic.

ROLES:
- Administrator: Dashboard, Donors, Donations, Campaigns, Messages, Reports, Settings
- Staff Member: Dashboard, Campaigns, Messages, Reports, Settings
- Donor: Dashboard, Campaigns, Donations, Settings

HOW TO RUN:
1. Start XAMPP Apache and MySQL.
2. Copy this folder to: C:\xampp\htdocs\donor_management_role_based
3. Open phpMyAdmin.
4. Import database.sql.
5. Open: http://localhost/donor_management_role_based/index.php
6. Register using Administrator, Staff Member, or Donor.

IMPORTANT:
This website uses the same role names as the Android app:
Administrator, Staff Member, Donor.
